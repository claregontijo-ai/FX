# AuroraFX

Mod visual para Minecraft 1.8.9 (Forge): Target Aura, Hit Effect, Trails e Island HUD. Menu: RShift.

## Como compilar
1. Baixe o Forge 1.8.9 MDK (1.8.9-11.15.1.2318) e copie `src/` e `build.gradle` deste projeto por cima dele.
2. Use JDK 8 e rode `./gradlew setupDecompWorkspace` e depois `./gradlew build`.
3. O jar sai em `build/libs/`. Coloque na pasta `mods` do Forge 1.8.9.

## Build automático (sem instalar nada)
Suba esta pasta para um repositório seu no GitHub. Em Actions > "Build AuroraFX" > último run, baixe o artefato `AuroraFX-jar` (o .jar que vai na pasta mods).
